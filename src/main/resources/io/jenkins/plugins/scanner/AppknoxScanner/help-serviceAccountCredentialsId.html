Select the credential holding your Appknox Service Account -- a "Username with password" credential where the Username is the Service Account's Access Key ID and the Password is its Access Key Secret, both from your Appknox dashboard (Organization > Settings > Service Account). A Service Account is created there by an organization owner or admin.

Provide exactly one of Appknox Access Token or Appknox Service Account -- not both. Leave this set to "- none -" when using a Personal Access Token instead.
